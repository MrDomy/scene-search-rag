# RAG-поиск по художественной литературе

Прототип системы семантического поиска сцен в художественной прозе по описанию события (на базе рассказов Роберта Шекли). Написан с нуля на Python без использования фреймворков вроде LangChain.

## Стек
* **Эмбеддинги:** `intfloat/multilingual-e5-small` (`sentence-transformers`)
* **Поиск:** косинусная близость через матричное умножение (`numpy`)
* **Генерация ответа (LLM):** `gemini-2.5-flash` (`google-genai`)
